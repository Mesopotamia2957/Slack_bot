# JerryBot — 채용공고 키워드 알림 슬랙봇

관심 키워드를 등록해두면, 그 키워드에 맞는 **새 채용공고**가 올라올 때 슬랙 DM으로 링크와 함께 알려주는 봇입니다.

```
사용자: !키워드추가 백엔드 django

  (이후 새 공고가 올라오면)

JerryBot: 🔔 등록하신 키워드에 맞는 새 공고 2건이 올라왔어요.

          🏢 네이버
          • [NAVER] 백엔드 개발자 (경력)   (마감 2026.08.03 ~ 2026.08.18)
          • [네이버웹툰] 백엔드 엔지니어    (마감 상시)
```

공고 제목이 그대로 링크라서 바로 눌러 들어갈 수 있습니다.

---

## 저장소 두 개가 한 쌍입니다

| 저장소 | 역할 |
|--------|------|
| **Slack_bot** (이 저장소) | 슬랙에서 명령을 받아 서버에 물어보고 답한다 |
| **JerryBot_V2** | 채용 사이트를 크롤링해 DB에 쌓고, API를 제공하고, 알림을 보낸다 |

```
 [슬랙 사용자]                          [cron 배치]
      │ !백엔드 검색                          │ 하루 2회
      ▼                                      ▼
 ┌──────────┐    REST API    ┌───────────────────────┐
 │ Slack_bot │ ─────────────▶ │      JerryBot_V2      │
 └──────────┘                │  크롤링 → DB → 알림     │
      ▲                       └───────────────────────┘
      │  슬랙 DM (키워드 매칭된 새 공고)          │
      └──────────────────────────────────────┘
```

크롤링은 배치가 미리 해두기 때문에, 슬랙에서 명령을 치면 **DB만 읽어 즉시** 답합니다.

---

## 사용법 (슬랙에서)

봇에게 DM을 보내거나, 봇이 있는 채널에서 입력하세요. `!도움말` 을 치면 언제든 아래 내용을 볼 수 있습니다.

### 처음 시작하기

```
!키워드추가 백엔드
```

이게 전부입니다. 이후 키워드에 맞는 새 공고가 올라오면 DM이 갑니다.

### 공고 보기

| 명령어 | 설명 |
|--------|------|
| `!목록` | 지원하는 기업과 각 기업의 진행 중 공고 수 |
| `!네이버` | 해당 기업의 진행 중 공고 (기업명을 그대로 입력) |
| `!검색 백엔드 django` | 모든 기업에서 키워드로 검색 |

### 내 키워드

| 명령어 | 설명 |
|--------|------|
| `!키워드` | 내가 등록한 키워드 보기 |
| `!키워드추가 백엔드 서버` | 키워드 등록 (공백이나 쉼표로 여러 개) |
| `!키워드삭제 백엔드` | 키워드 삭제 |
| `!내공고` | 내 키워드에 맞는 공고 전부 보기 |
| `!알림 끄기` / `!알림 켜기` | DM 알림 on/off |
| `!도움말` | 사용법 안내 |

`!` 를 빼먹고 DM을 보내면 봇이 짧게 안내해 줍니다. 공개 채널에서는 `!` 로 시작하는 메시지에만 반응하므로 대화를 방해하지 않습니다.

### 키워드가 동작하는 방식

- 공고의 **제목과 직군**에서 키워드를 찾습니다.
- 대소문자를 구분하지 않습니다. `Django` 와 `django` 는 같습니다.
- 키워드를 여러 개 등록하면 그중 **하나라도** 맞는 공고를 보냅니다 (OR 조건).
- 한 번 보낸 공고는 다시 보내지 않습니다.
- 별도 가입이 없습니다. 슬랙 사용자 ID로 구독자가 자동 생성됩니다.
- 개인 알림이 공개 채널에 노출되지 않도록, **알림 채널은 DM에서 말했을 때만** 저장합니다. 공개 채널에서 키워드를 등록해도 알림은 DM으로 갑니다.

## 설치와 실행

### 1. 의존성 설치

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 2. 슬랙 앱 설정

api.slack.com 에서 앱을 만들고 아래를 설정합니다.

- **Socket Mode** 켜기 → `xapp-` 로 시작하는 App Token 발급 (`connections:write` 필요)
- **Bot Token Scopes**: `chat:write`, `im:history`, `im:write`, `channels:history`, `app_mentions:read`
- **Event Subscriptions**: `message.im`, `message.channels`, `app_mention`
- 워크스페이스에 설치 → `xoxb-` 로 시작하는 Bot Token 발급

Socket Mode 를 쓰므로 공개 URL 이나 웹훅 주소가 필요 없습니다.

### 3. 환경변수

`.env.example` 을 복사해 `.env` 를 만들고 채웁니다.

```bash
cp .env.example .env
```

| 변수 | 설명 |
|------|------|
| `BOT_TOKEN` | `xoxb-` 로 시작하는 봇 토큰 |
| `APP_TOKEN` | `xapp-` 로 시작하는 소켓 모드 토큰 |
| `URI` | JerryBot_V2 API 주소. 예: `http://localhost:8000/api/` |
| `API_KEY` | 서버에 `JERRYBOT_API_KEY` 를 설정했다면 같은 값 (선택) |
| `REQUEST_TIMEOUT` | API 응답 대기 초 (기본 10) |
| `MAX_ITEMS` | 한 메시지에 넣을 공고 수 (기본 25) |

### 4. 서버부터 띄우기

봇은 JerryBot_V2 API 를 호출하므로 서버가 먼저 떠 있어야 합니다.

```bash
cd ../JerryBot_V2/JerryBot_V2 && ../.venv/bin/python manage.py runserver
```

### 5. 봇 실행

```bash
.venv/bin/python slack_command.py
```

## 프로젝트 구조

```
Slack_bot/
├── slack_command.py     진입점. 앱을 만들고 리스너를 붙여 Socket Mode 로 실행
├── jerrybot/
│   ├── config.py        .env 로드와 검증
│   ├── api.py           JerryBot_V2 API 호출 (타임아웃·에러 처리)
│   ├── formatting.py    슬랙 메시지 생성 (제목이 링크가 되도록)
│   └── handlers.py      명령 해석과 처리
└── tests/
    └── test_handlers.py
```

**기업이 추가돼도 이 저장소는 고치지 않습니다.** `!` 로 시작하는 메시지를 단일 핸들러가 받아
서버에 조회를 위임하므로, 기업 추가는 JerryBot_V2 의 `Crawling_App/sites.py` 만 수정하면 됩니다.

새 명령을 추가하려면 `handlers.py` 에 `cmd_*` 함수를 만들고 `COMMANDS` 딕셔너리에 등록하면 됩니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|------|-----------|
| 봇이 뜨자마자 `ConfigError` | `.env` 에 `BOT_TOKEN`, `APP_TOKEN`, `URI` 가 있는지 |
| "공고 서버에 연결할 수 없습니다" | JerryBot_V2 서버가 떠 있는지, `URI` 가 맞는지 |
| "서버 응답이 너무 느립니다" | 서버가 크롤링 중일 수 있음. 크롤링은 배치로 분리돼 있어야 정상 |
| 명령에 반응이 없음 | Event Subscriptions 와 Bot Token Scopes 설정 확인 |
| 공고는 나오는데 DM 알림이 안 옴 | 서버 `.env` 의 `SLACK_TOKEN`, 그리고 서버에서 `crawl_jobs --notify` 가 도는지 |
